# 🐍 Classic Snake – Traditional Edition

A retro-style **Snake Game** built using **HTML, CSS, and JavaScript**, inspired by classic LCD-style gaming. This project recreates the nostalgic feel of early mobile snake games with a minimal and clean UI.

---

## 🎮 Features

* 🟢 Classic snake movement gameplay
* 📟 Retro LCD-style design
* 📊 Live score tracking
* 🏆 High score display
* ⌨️ Keyboard controls (Arrow keys)
* ⏯️ Start / Pause / Game Over overlay
* 📱 Responsive scaling for smaller screens

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling (Retro LCD theme)
* **JavaScript** – Game logic (Canvas-based rendering)

---

## 📁 Project Structure

```
classic-snake/
```

## 🎯 Controls

| Key            | Action     |
| -------------- | ---------- |
| ⬆️ Up Arrow    | Move Up    |
| ⬇️ Down Arrow  | Move Down  |
| ⬅️ Left Arrow  | Move Left  |
| ➡️ Right Arrow | Move Right |
| ⏎ Enter        | Start Game |
